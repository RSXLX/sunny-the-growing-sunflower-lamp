# 从这里开始

**软件演示：**电脑已有Python3.10+时，在当前目录执行 `python3 run.py`，浏览器打开 `http://127.0.0.1:8787`。Mac可以执行 `bash start.command`；Windows使用 `start.bat`。

**账号：**`alice@bloom.local` / `BloomDemo!2026`。第二账号 `bob@bloom.local`，密码相同。仅用于本地演示。

**硬件制作：**先读 `docs/HARDWARE.md` 和 `docs/PRINT_AND_ASSEMBLY.md`。CAD在 `hardware/cad/`，STL在 `hardware/exports/`，接线和BOM在 `hardware/electronics/`，固件在 `hardware/firmware/`。

**真实性：**软件默认不收费，不调用AI。真实Tripo适配器需要自己的key联调。未完成真实硬件制造与验收；固件纯逻辑已测，完整板级构建/刷机未完成。详见 `docs/TEST_REPORT.md`。
