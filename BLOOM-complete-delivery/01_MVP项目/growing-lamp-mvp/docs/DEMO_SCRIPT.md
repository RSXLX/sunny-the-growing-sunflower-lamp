# 三分钟展示脚本

**只有软件时**请直接称“数字工作流＋硬件工程原型包”。没有真实灯的动作就展示模拟器标识，不把网页动画当实物。

0:00–0:20：我的房间。「刚搬来的房间还没有我的样子。」已有向日葵灯和光影示意。实体已经验证时，按真实按钮开灯。

0:20–0:45：成长记忆，保存搬家第一晚的文字。说明原始记忆默认私有，生成服务只收到用户重新确认的视觉描述。

0:45–1:15：外装工作室，展示本地参数化生成或真实Tripo任务。若是Tripo，展示task_id与原稿；不要给参数化演示贴AI标签。耗时任务可用之前完成的、与文件对应的任务，但必须说明不是现场瞬间完成。

1:15–1:45：我的衣橱，下载ZIP，打开实际模型、接口和制造清单。实体已存在时穿插实际Blueprint、打印、后处理录像；没有实物就明确说这里是待制造交付包。

1:45–2:15：创建实例并绑定。模拟器流程保持模拟标签可见；真实硬件则靠近空白标签并按键写入，读回后移开，再安装，查看outfit_installed事件和实际灯光。

2:15–2:40：发布设计，切第二个账号，基于该设计再创作。回看第二账号记忆页，不会看到原始私人日记。

2:40–3:00：「成长不是每天多一个经验值，而是某段生活，真的变成了房间里的一件东西。」真实三件外装同底座展示最好；未制造则展示工程结构图并说明下一轮硬件验收项。

备用：API断网用已完成模型＋明确演示模式；打印失败不换成其他作品冒充；准备备份和两账号登录，但不预置虚假社区人数或长期使用天数。
