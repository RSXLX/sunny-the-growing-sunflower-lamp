# 模型预览与可追溯适配

2026-09-22 软件实现。没有使用真实 Tripo 返回样例，也未执行打印、装配、温升验证。

## 使用入口

衣橱 → 设计的「制造版本」：

1. 「预览此版本」可切换原稿比例、装饰适配草案和最终 STL（仅显示该版本实际拥有的文件）。最终 STL 可进入灯体数字试装。
2. 「调整朝向与尺寸」填写参数和修改说明，确认后生成新草案。旧文件、审核记录和已有制作实例不会自动改用新版本。
3. 有原始 GLB 的版本始终从该原稿重新适配；人工 STL 修正不会累积到这次原稿适配中。只有最终 STL 的版本仅能绕 Z 安装轴旋转；尺度、倾斜或接口修改应在建模工具内完成后导入修正版。
4. 原始 GLB 可由拥有者单独下载。旧版本没有预生成原稿预览时不会就地补写；从旧版本建立新版本才能获得新的预览文件。

## 读取范围

`app/gltf.py` 是 GLB 几何解析的唯一实现，浏览器读取服务端生成的 STL。基于 [Khronos glTF 2.0 规范](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html) 实现的范围：

- GLB 2.0 内嵌单一 BIN；默认场景、父子节点 matrix/TRS、负尺度绕序修正。
- POSITION 浮点及 KHR_mesh_quantization 整数量化；normalized、交错存储及稀疏 accessor。
- TRIANGLES、TRIANGLE_STRIP、TRIANGLE_FAN；索引、边界、有限坐标和循环节点校验。
- 文件上限 50 MiB，单 accessor 上限 300000 元素，总计 100000 三角形、1500000 解码标量；节点/视图/accessor 各最多 4096、节点深度最多 64。

当前明确拒绝：外部 buffer、Draco/Meshopt 压缩、骨骼、动画、形变目标、不支持的必要扩展及非三角形 primitive。这是静态几何子集，不是完整 glTF 查看器；不显示材质、纹理或动画。不支持/损坏模型会返回错误，不换用预置模型。STL 浏览器下载上限 12 MiB。

## 坐标、单位与参数

原始模型先做 Y-up → Z-up 映射 `(x, -z, y)`，保留原有比例。`original-preview.stl` 保留原场景坐标，**不是制造毫米模型**；浏览器只为视图居中和等比缩放。其用途和单位写入 `preview-report.json`，不应直接送去打印。

适配支持按 X、Y、Z 顺序旋转（每轴 -180° 至 180°），目标平面包围宽度 50–196 mm、装饰深度 1–20 mm：

- `uniform`：保持原稿比例，放进宽度/深度共同限定的空间；较薄一维可能导致实际平面宽度小于目标。
- `fit_depth`：平面等比、深度独立缩放；会改变三维比例，界面明确提示。

适配结果 `raw.stl` 以毫米输出，装饰底部位于 Z=4。OpenSCAD 脚本另行建立固定载体与环形裁切；缺少转换器或执行失败时不保留最终 STL，也不能通过制造批准。数字试装不验证公差、接触、夹持力、壁厚或热安全。

最终 STL 的 Z 旋转保留各点到安装轴的距离及 Z 高度；旧接口快照不同于当前接口时禁止直接调整。接口升级仍需要单独的迁移/人工修正流程。

## 文件与审核

新版本固定保存源版本 ID、源文件 SHA-256、算法、参数、接口和适配报告。`transform.json`、原始 GLB 与原稿预览仅对拥有者开放；公开版本继续按允许列表只提供最终 STL 和必要制造报告。每次读取或打包都核对哈希。

本轮适配测试使用明确标记的合成四面体，不代表 Tripo 实际输出兼容性。OpenSCAD 成功转换尚未实测，缺少工具时的拒绝制造路径已验证。完整几何拓扑、连接性、薄壁、碰撞、公差和实体结果仍需进一步验证。

## 验证

根目录 `.venv/bin/python check.py`。浏览器专项：

```bash
.venv/bin/python BLOOM-complete-delivery/01_MVP项目/growing-lamp-mvp/tests/browser_geometry.py \
  --output evidence/geometry-browser
```

需安装 Playwright 浏览器，或提供 `--chromium` 路径。专项自建隔离的本机 HTTP 服务，不启动生成 Worker，不调用付费 API。
