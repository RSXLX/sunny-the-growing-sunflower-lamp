# 硬件：接线、烧录与上电

**这是5V模块级原型，不是成品安全认证。没有完成实体组装、烧录和热测试。**通用采购规格见 `hardware/electronics/BOM.md`；图见 `hardware/electronics/wiring.svg`，精确逻辑连接见 `netlist.json`。

## 1. 电气设计

只用外置成品隔离稳压5V电源；灯里不布市电。建议5V/2A供电，经保险丝和防反接保护后供ESP32 VIN与两路5V自带限流LED。所有模块共地。PN532使用确认支持3.3V供电与逻辑的版本，不把5V信号直连ESP32。

| ESP32 GPIO | 接到哪里 | 说明 |
|---|---|---|
| 25 | 主照明MOSFET门极串100Ω | 门源100kΩ下拉 |
| 26 | 投影MOSFET门极串100Ω | 门源100kΩ下拉 |
| 18 | PN532 SCK | 模块跳线/拨码设SPI |
| 19 | PN532 MISO | 模块返回 |
| 23 | PN532 MOSI | 主控输出 |
| 27 | PN532 SS | 不依赖默认SS脚 |
| 33 | 常开按键到GND | INPUT_PULLUP |
| 34 | 温度分压中点 | ADC1，不能悬空 |

低边MOSFET：LED正极接保护后5V，负极接Drain，Source接GND，Gate为PWM。必须选择在≤3.3V VGS下明确给出导通电阻的器件/模块，不根据阈值电压猜测。两路必须自带LED限流，不允许直接使用裸高功率灯珠。

NTC连接为 `3V3 → 10kΩ固定电阻 → ADC34节点 → 10kΩ B3950 NTC → GND`；ADC节点并100nF到GND。电阻方向不能颠倒，否则温度公式反向。NTC绝缘固定在实际测得最热的位置，不能短接。主光源与分体投影源需要分别测热，单传感器不代表覆盖所有局部热风险。

## 2. 固件环境
使用 `hardware/firmware/platformio.ini` 固定平台6.9.0（Arduino-ESP32 2.0.17）、Adafruit PN5321.3.4、BusIO1.16.1、ArduinoJson6.21.5。不是最新版本推荐，而是为了保持代码使用的LEDC通道API一致。升级到Arduino3.x前需迁移LEDC接口并重新测试。

已在电脑编译执行 `test/logic_test.cpp`，验证纯C++核心。**没有在此环境运行 PlatformIO 全板构建**；builder电脑安装PlatformIO并联网下载依赖后执行：

```bash
cd hardware/firmware
cp include/config.example.h include/config.local.h
# 填Wi-Fi、服务器局域网IP与工作台给出的token
pio run
pio run -t upload
pio device monitor
```

凭据文件已在.gitignore排除。先使用USB供电烧录时，外部5V拔掉；外供电调试串口时使用不带VBUS的串口方式/合适隔离，禁止两路电源直接互灌。

## 3. 分阶段上电，不一步全接

第一阶段断开所有电源，用万用表检查5V/GND无短路、MOSFET方向、NTC分压、按钮接地以及PN532SPI模式。记录实际模块型号与尺寸。

第二阶段只接ESP32和NTC，USB供电并看串口，核对温度合理且fault=false。断开NTC应锁定关闭；恢复后冷却至45°C以下并长按5秒复位。不要以手指感觉替代温度测量。

第三阶段连接PN532，读取空白标签，确认读卡器初始化成功。用工作台创建设备并确认真实在线。读卡失效不应阻塞按键与安全采样。

第四阶段断电后接两路受限LED及外置保护电源。先低亮度短时运行，再接投影附件。主PWM默认≤60%，投影≤35%；仍要测模块、电线、外壳和胶粘处温度。这些百分比不是安全认证。

第五阶段创建实例、记录实际打印与装配，点击NFC绑定，90秒内靠近标签并短按按键。观察写入读回成功，移开再安装，网页应出现真实换装事件。

## 4. 本地交互与保护
短按开关；长按600ms后循环调光。等待绑定时短按变成显式写入授权。故障状态须冷却并长按5秒复位，复位后仍保持关闭，需再次主动开灯。

NTC无效或≥55°C锁定关闭；回落不会自动重亮。投影连续15分钟自动关闭，上电不恢复投影。未联网时使用本地存储的状态和标签缓存，不能创建新绑定。

## 5. 必须补齐的实测
满亮度、堵塞通风、投影插片误装、NTC断开/短路、Wi-Fi断开/重连、按钮卡住、标签反复进出、供电瞬断和连续运行。测读卡位置、成功率、最大外装质量、夹持力、底座倾倒、线材应力与表面温度。未通过前不送给儿童、不离人运行、不作商业出货。

此版光源只定位低功耗氛围/基础照明演示，未测照度、显色、闪烁或蓝光危害，不宣传护眼、治疗或标准办公照明。
