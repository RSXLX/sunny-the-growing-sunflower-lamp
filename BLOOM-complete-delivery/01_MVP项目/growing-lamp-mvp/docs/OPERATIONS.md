# 运行、备份与排错

## 配置与部署
默认仅监听127.0.0.1，可信本机使用。API、静态页、数据库和文件均在一个进程/主机上；不会自动部署至Vercel或公网。不需要Redis/MySQL/云账户。

`.env` 只在启动时读取；真实key或配置修改后重启。已有环境变量优先于.env。支持HOST、PORT、DEMO_MODE、ALLOW_LAN、TRIPO_API_KEY、TRIPO_API_BASE、TRIPO_MODEL_VERSION、TRIPO_POLL_SECONDS、COOKIE_SECURE。TLS反向代理下配置COOKIE_SECURE=1；普通HTTP本机不要设1，否则浏览器不能正常送Cookie。

## 备份

停止服务后执行：

```bash
python3 tools/backup.py --data data --out backups
```

脚本用SQLite backup API复制数据库并复制assets目录，包含私人日记和账户哈希，应按敏感资料保存。运行中备份数据库本身一致，但数据库与资产文件的跨资源快照不保证同时；因此完整备份应先停止服务。

恢复：先停止服务，将备份目录中的bloom.sqlite3和assets恢复到一个新数据目录，再以`--data`启动。不要把不同时间点的数据库与模型目录混用。

## 排错

| 现象 | 检查 |
|---|---|
| 页面打不开 | 终端是否还在运行；是否有Python3.10+；8787是否被占用；更换`--port 8788` |
| 手机/ESP32连不上 | 用电脑局域网IP，不是127.0.0.1；同网段；ALLOW_LAN=1；应用端口防火墙允许可信网段 |
| 模型预览无WebGL | 自动使用Canvas软件三维绘制；数据仍来自实际STL/未压缩GLB；可下载文件外部查看 |
| Tripo按钮不可选 | .env是否填key并重启；不是将key填在浏览器 |
| 任务结果待核对 | 检查Tripo控制台，不反复生成；填写已有任务ID恢复 |
| 适配失败 | 保存原始GLB；检查压缩类型/朝向/薄壁；安装OpenSCAD或人工修复 |
| 实体灯离线 | token、服务器URL、2.4GHz Wi-Fi、串口错误码；创建身份不等于在线 |
| 401持续出现 | 设备token已旋转或填错；勿打印token到公开日志 |
| LED不亮 | 先看温度fault，核对NTC接线与门极/限流模块；不能关闭保护代码应付演示 |
| NFC无法写 | PN532模式/连线；空白可写NTAG213；标签靠近；绑定期限内短按实体按钮 |
| 绑定后未换装 | 移开标签，再装入天线位置；等待缓存同步；检查不是演示绑定实例 |
| 数据异常/数据库锁定 | 不要运行两个进程操作同一data；保存日志并停止服务后备份 |

## 安全范围
内置HTTP服务器是本地MVP，不是公开多租户SaaS。不要以关闭Host/CSRF检查解决公网部署。真实上线需维护中的服务器栈、TLS、访问控制、限流、隔离模型处理、持久任务租约与运行审计。
