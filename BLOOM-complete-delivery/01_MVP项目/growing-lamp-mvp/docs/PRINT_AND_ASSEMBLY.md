# 打印与机械装配

## 文件与坐标
全部几何为毫米，STL自身不携带单位，切片时明确选择mm。`hardware/cad/lamp.scad` 是原生可编辑源，`part="assembly"` 显示结构示意；`exploded` 可拉开头部与底盖。装配示意使用随包 sunflower STL，不代表实物照片。实际花冠从 `hardware/exports/crown_*.stl` 或设计制造ZIP获得。

| 文件 | 用途 |
|---|---|
| base_shell / base_lid | Ø140mm底座外壳与底盖、通风、线缆口、按钮口 |
| head_core / head_socket | 发光核心、NFC非金属侧翼、灯杆夹持支架 |
| retainer | 三螺丝压环，固定外装 |
| leaf_button | 按键叶片外观件，适配实际开关后使用 |
| fit_coupon / crown_coupon | 12.2/12.4/12.6mm孔与76mm半环试片 |
| gobo_body / lens_holder / lens_retainer | 投影筒、调焦镜筒、镜片压环 |
| gobo_forest / gobo_stars | 手动树影/星点插片 |
| projector_cradle | 独立有线投影组件支架 |
| crown_sunflower / crown_forest / crown_stars | 三套共接口参数化外装 |

共17个STL，其中包括2个试片与3套花冠，不是17个都要同时装在一盏灯上。示例花冠都是本项目参数化模型，不是Tripo实物成果。

## 接口规格 v1
花冠中心孔Ø76，灯头定位台Ø75，径向间隙名义0.5。夹持区域半径38–43，厚度4；压环外径86，3颗M3螺钉位于BCD70。花冠最大外径196、厚度24。螺钉位于中心孔内侧，通过压环搭接花冠边缘压紧；不要求AI生成精密螺丝孔。

花冠背面标签中心(0,-55)，目标最大22×22。NFC天线固定在头部非金属侧翼；胶层、板厚、支架及读距都要实测。避免在天线与标签之间放金属垫片。

灯杆采购OD12/ID8/长174mm管材；支架名义孔12.4。PN532板43×41mm和按钮孔8.2mm仅是设计假设，必须对照实际购买件调整。M3螺栓长度亦需根据实物测量确认，不能顶住灯板/线路。

## 先打试片
先打fit_coupon和crown_coupon，以实际机器、材料、清洗和固化流程测最终尺寸。检查收缩、孔径、插拔、最小壁厚和脆性，再决定补偿；不要给未指定材料套用一个虚假的通用曝光时间。

打印材料按供应商TDS/SDS选择。普通外观树脂不能直接视为耐热工程材料。洗净、完全固化、去支撑并磨掉锐边后再接触。不要将未固化树脂制件装在热源旁运行。

## 装配顺序
1. 检查所有实体无裂纹、漏固化与锐角。用卡尺测接口；不要强压脆性件。
2. 在base_lid固定绝缘电子模块、线束和必要的绝缘配重，预留导线与通风。底部加防滑脚。配重是待实测选型，不包含在打印件里。
3. 灯杆去毛刺，穿线并加护线套，插入底座夹持位，轻拧横向夹紧螺栓。使用独立止退/固定方法，测试不下滑。
4. head_socket固定在head_core后方，再与管杆连接。主灯板用绝缘支撑固定在头内，不能用松散胶点承受所有负载。
5. PN532装在侧翼，用尼龙支撑和扎带调整天线高度。先在未合壳状态试读标签，再确定间隙。
6. 将花冠平面夹持环放在定位台上，再加retainer。三螺栓配垫片与螺母均匀压紧，不要一次拧紧一边。标签朝向天线；可旋转角度校正位置。
7. 中心添加尺寸适合的扩散片并以可靠、可拆方式固定，不靠发热元件支撑扩散片。不得遮住散热出口。
8. 单独装投影筒：源侧受限LED → z≈25mm插片 → 可调镜筒/凸透镜 → 压环。投影组件通过线束接底座，是分体附件，不是假称一体化的隐藏组件。
9. 先通电低亮度调焦、测试NFC与温度，再封底盖。封盖后复测整机重心、抗倾倒和通风。

## 光学调试
投影片30×34×1.2mm，带抽取手柄；镜片目标直径25mm、名义焦距约35mm。滑动镜筒改变片到镜片距离，找到墙面清晰度再锁紧。源光斑、焦距误差、距离和环境亮度决定实际效果。

单片简单投影在弱光环境可能更明显，不保证白天或整个房间的星海。先在一面墙局部调试，记录距离、图案尺寸、光源型号与实拍曝光。星点和树影是两个实体插片，软件主题不代替物理换片。

数字网格封闭只是几何检查，不证明耐热、连接强度、读距、外观或实际光学质量。对Tripo生成原稿的孤立岛、薄壁、仅共面连接，必须人工处理。

## 重新导出

```bash
python3 tools/export_cad.py
# 或只重导出某件
python3 tools/export_cad.py --part head_core
```

导出需要OpenSCAD CLI，默认工作台无需它。查看 `cad-mesh-checks.json` 与每件日志；有异常不要跳过后直接声称可打印。
