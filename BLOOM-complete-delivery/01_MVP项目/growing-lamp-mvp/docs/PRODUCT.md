# 产品范围与交付地图

## 核心承诺
用户主动保存记忆，用视觉描述生成外装；数字设计与固定接口组合，经过人工制造与装配成为实物；外装标签触发可追溯的换装事件，公开设计允许另一人接续创作，原始记忆保持私有。

「成长」指记忆、设计版本和实物档案逐渐积累，不是自动长出物理零件。默认三套外装为向日葵、森林和星夜。它们共用夹持接口，不共用私人日记。

## 六页工作台

| 页面 | 已实现的操作 | 真实性边界 |
|---|---|---|
| 我的房间 | 3D 灯体/当前外装、开关、亮度、主题、独立投影亮度、设备切换 | 3D 房间光影是示意，不是投影光学仿真或实拍 |
| 成长记忆 | 新建、编辑、删除、关联创作 | 不上传原始日记；删除不会抹去已经主动写入设计提示词的内容 |
| 外装工作室 | 参数化/Tripo、收费确认、持久任务、实际模型预览、二创来源 | 参数化模式没有语义 AI；Tripo 原稿仍需制造检查 |
| 我的衣橱 | 模型预览、制造 ZIP、审查、实体实例、制作阶段、NFC 绑定/模拟换装、发布 | 已打印和装配检查是人工声明，设备绑定是回执事件 |
| 交换花园 | 公开设计、主题筛选、收藏、二创 | 两个账号验证关系；没有虚构社区活跃人数 |
| 硬件与联调 | 真实设备 token、在线状态、事件记录、结构件下载、接线和烧录指引 | 创建 token 不代表设备在线；首次有效上报后才在线 |

## 不在 1.0 中
没有对话机器人、情绪诊断、人脸追踪、多轴机械运动、支付物流、自动下发 HeyGears 打印、任意图案自动切换、AI 模型一键安全认证、生产级多租户云托管。

图片/语音日记、实时语义生成投影片和手机 Web NFC 没有实现。记忆首版为文字和主题，光效为固定两路 PWM 与手动插片。不是全光谱 RGB 灯，也不声称满足办公照度。

## 可演示与可制造的区别
离线演示闭环可完整操作；参数化 STL 与固定零件可导出。完整硬件闭环仍需要采购、打印、组装、烧录和实测。没有上述证据前，只能展示为工程原型包，不能声称已经完成实物产品。

## 建议现场验收
在同一实体底座上轮换三件外装。连续 20 次换装目标为至少 19 次正确识别；反复读取同一标签不增加重复成长事件。断网情况下仍可本地开关、调光、识别已缓存的 16 件外装。温度异常与传感器断开时必须关闭输出。上述为待测目标，不是已经取得的硬件成绩。
