# Tripo 接入、参考图与失败恢复

## 配置与输入

在应用目录复制 `.env.example` 为 `.env`，配置 `TRIPO_API_KEY`。按允许创建的任务数设置 `TRIPO_MAX_SUBMISSIONS`，然后重启。密钥仅供后端使用，不写入前端、任务快照或制造包。

当前默认使用官方 v3 接口 `https://openapi.tripo3d.ai/v3` 和 `v3.1-20260211` 模型。支持配置 `v3.0-20250812`、`v2.5-20250123`；当前账号的可用性仍须实测。固定请求无纹理、非 PBR、20000 面上限，不请求网格压缩或四边形输出。

- 文字：`POST /generation/text-to-model`；视觉描述最多 1024 字符。
- 图片：清理后的 PNG 经 `POST /files` 上传获得 file_token，再调用 `POST /generation/image-to-model`。图片模式只发送图片，上方文字作为本地设计说明，不能宣称文字控制了图生结果。
- 查询：`GET /tasks/{task_id}`。成功输出从 `output.model_url` 获取。

工作室会先展示实际发送的图或文字与模型参数。确认后保存接口、模型、输入模式、时间、图片哈希及文字请求快照。确认时配置与服务器不一致会拒绝创建，要求重新核对。用户原始日记不会自动拼接发送。

## 参考图处理与访问

安装 `requirements.txt` 中的 Pillow 后，支持单帧 JPEG/PNG：原始/清理后文件不超过 8 MiB，至少 16×16，最多 1200 万像素及 6000 像素边长。完整验证并解码图片，校正 EXIF 方向，重新编码为 PNG，移除 EXIF、ICC、文本等元数据。不保存上传的原始字节。

每个账号最多保存 100 张 / 200 MiB 参考图。路径由服务生成，不使用用户文件名。内容按 SHA-256 检查；图片默认私有，公开设计或制造包都不包含参考图。图片已经被任务引用时禁止删除，未引用图片可从工作室删除。

仅在任务已经确认后将图片发给 Tripo。上传到 BLOOM 本机参考图库本身不会发起外部请求。

## 任务与提交次数

`TRIPO_MAX_SUBMISSIONS` 是这个本地数据库中累计保留的任务名额，多个本地账号共享；不是金额、积分余额或计费保证。任务创建时事务化占用一个名额，同一幂等键返回同一任务；失败、被拒绝、提交结果未知也不自动返还名额。默认 0。增加数值会允许继续创建新任务，不影响已有任务查询。

阶段区分为排队、上传参考图、提交、查询、下载、准备制造草案和待人工检查。生成完成率到 100% 仍不代表文件已下载或制造已批准。

| 情况 | 行为 |
|---|---|
| 提交前密钥缺失或本地配置无效 | `configuration_failed`；修复配置后恢复原本地任务，不新增任务名额 |
| 图片上传失败 | `upload_failed`；可以重新上传相同已确认图片，此时尚未提交模型生成 |
| POST 结果未知、提交期间中断、任务 ID 未能落盘 | `submission_unknown`；停止自动提交，用户核对控制台后关联已有任务 ID |
| 已知任务查询或模型下载暂时失败 | 最多 5 次退避重试，然后进入 `poll_failed` 或 `download_failed`；恢复继续查原 ID |
| 原稿已保存，后续本地准备失败 | `preparation_failed`；恢复只处理本地原稿，不重新生成或重新下载 |
| 转换器不支持或适配失败 | 保留原稿并标记人工处理；失败的部分 STL 不作为最终文件 |
| 供应商明确拒绝或终态失败 | 不自动新建付费任务；已有关联 ID 不允许换成另一个 ID |

上传令牌和原始文件校验记录仅在后端保存，不通过公开设计泄露。供应商身份凭据不跟随 HTTP 重定向发送。

## 旧 v2 任务

显式配置 v2 的新文字任务仍使用 `/task` 和 `/task/{id}`，不支持 v2 图片路径。任务保存时冻结其配置，随后改变全局配置不影响已有任务。

更旧的数据没有记录请求配置，迁移时按历史默认 v2 地址与 v2.5 模型补充，并标记 `legacy_assumed`；界面会说明这是兼容假设。若旧任务实际使用了另一地区或模型，需核对历史账号记录，不能把假设视为真实原始请求证据。

## 几何适配与制造

1. 保存原始 GLB 和校验值。
2. 本地最小读取器处理未压缩内置三角网格及节点变换；不支持的资产进入人工处理流程。
3. 默认 Y-up → Z-up、平面居中缩放至 190 mm、深度压至 16 mm，再放到 z=4 以上；此变换会改变比例，仍需人工审核。
4. 导出 raw.stl 和 adaptation.scad，执行环形裁切并保留固定载体；有 OpenSCAD 时尝试生成 crown.stl。
5. 创建独立制造草案，文件和接口随版本固定。可通过网页导入人工修正的 STL 建立新版本，不原地覆盖批准文件。

提示词提到 printable 不等于可制造。连接、薄壁、自交、配合、材料及实物效果依然需要工程检查。
