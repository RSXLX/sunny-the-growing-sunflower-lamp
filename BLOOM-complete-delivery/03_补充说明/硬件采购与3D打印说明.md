# 硬件采购与 3D 打印说明

数量基准：**1 盏灯＋3 套可换花冠＋1 套分体光影组件**。本文件整理此前硬件清单；原采购工作簿和源文件保留在 `02_硬件与3D清单/`。所有型号与尺寸是原型约束，不是实购或实测记录。未提供定制 PCB Gerber。

## 4. 打印与装配前提

先处理 `打印前必读_已知问题与验证边界.md` 中列出的结构问题。先打印 `fit_coupon.stl` 与 `crown_coupon.stl`，用实际材料、机器、清洗和固化流程测收缩与配合。不要为未选定树脂套用通用曝光参数。

按实际打印机成型空间、支撑与排版检查底座和接近 190 mm 的花冠。不能为了放入平台整体缩放，否则灯杆孔、透镜位、NFC 安装位和螺丝孔都会改变。必要时改为分件结构。材料需要分别考虑韧性、热环境与不透光要求。

原项目装配说明仍保留，但其中的可靠固定、散热、灯板和模块安装等通用要求，需要按实购物料落实为结构，不能把文字要求当成已经完成的 CAD。

## 5. 制作工具

电脑与可互通的 2.4GHz Wi-Fi、万用表、游标卡尺、温度计或热电偶、焊台与基本钳具、螺丝刀、打印与后处理服务。首次分阶段上电建议使用限流可调电源。打印机可以借用或外包，不必为一次原型专门购买。

## 6. 推荐顺序

先采购关键样件并测量 → 修订 CAD 与固定结构 → 打配合及光学试件 → 低压电路和 NFC 台架测试 → 打完整灯体与三套花冠 → 烧录与设备联调 → 温度、倾倒、光学和耐久测试 → 记录真实制作证据。
