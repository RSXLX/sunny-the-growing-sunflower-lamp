# BLOOM 开发任务清单 v3

日期：2026-09-22。所有任务当前为 planned；已有代码是基础，不代表下列新增工作已完成。人日为净工作量区间，不含到货、打印排队和外部响应。S=软件，H=硬件/嵌入式/结构，P=产品/验证/展示。P 无独立人员时必须占用 S/H 产能。

R0=参赛目标能力，R1=完整 MVP 新增能力，R2=可选增强；R0 集合仍需估算后裁剪，不能自动解释为两周承诺。R1 发布必须完成 R0 与 R1 的适用项。

每个任务只在交付物存在、验收记录通过且关联版本明确后改为 done。阻塞填写原因和负责人，不以空白代替。
