本页上半部分记录第一轮制造模块；最新参考图、Tripo 及模型适配进展见文末增量记录。

## 当前可以运行的流程

登录 → 保存私人记忆 → 本地参数化外装生成 → 设计检查 → 制造版本提交及人工检查 → 选择固定版本创建制作档案 → 模拟 NFC 绑定及换装 → 发布指定版本 → 另一账号二次创作。

本地参数化生成不调用 Tripo；模拟设备不代表硬件已经执行。已批准制造版本表示本地审核记录，不表示打印、装配、温升或安全认证通过。

## 本轮实现

- 工程：根目录启动/检查入口、秘密与运行数据忽略规则、根 CI 工作流。本地使用 Python 3.13.14；原生浏览器测试依赖单独放在 `.venv`。
- 数据：顺序增量迁移、迁移前 SQLite 一致性备份及完整性检查、迁移失败原子回滚。历史实例保持原记录并标记来源待核实，不自动获得制造批准。
- 制造：不可变资产目录、SHA-256 清单、递增版本、修正版来源；12 MiB STL 上限及毫米单位确认。新生成、导入修正版都建立独立版本。
- 审核：草案 → 已提交 → 批准/驳回；批准后可撤销。缺少最终 STL、基础网格失败或未完成必要人工确认均不能批准。文件被修改或丢失时，制造包与新实例创建会被拒绝。
- 制作：实例固定引用批准版本；打印、失败、重试、装配验证记录独立保存。照片/附件、完整返工界面尚未完成。
- 分享：用户选择要公开的版本，文件通过允许列表发布；后续私有修正版不会自动公开；原图、私人记忆和原始文件不随制造包公开。
- 设备服务：轮询、事件、回执及状态更新放在同一事务；重复事件须内容一致；仅收到绑定命令 ACK 不等于 NFC 写入读回完成；撤销版本阻止新增绑定。
- 前端：制造版本列表、预览、哈希、审核、导入、版本选择和制作记录。房间中已安装的实例使用其固定版本模型。
- 修复浏览器真实发现的问题：退出等无业务参数请求也读完 JSON 请求体，避免 HTTP/1.1 下一次请求被残留内容破坏；错误请求关闭连接。

## 运行与测试

在项目根目录运行：

```bash
.venv/bin/python run.py --port 8787 --data .runtime/software-demo
.venv/bin/python check.py
```

访问 `http://127.0.0.1:8787`。界面提供两套演示账号入口；数据持久化在 `.runtime/software-demo`，不进入源码版本管理。迁移前数据库备份放在所用数据目录的 `backups` 中；这只是迁移数据库备份，不是包含模型文件的完整灾备包。

浏览器测试（另一个终端，服务保持运行）：

```bash

  --url http://127.0.0.1:8787 \
  --output evidence/browser-current
```

Playwright 需要安装对应 Chromium，或者用 `--chromium` 指定本机可用可执行文件。测试会写入带 QA 标记的演示数据，使用专门的数据目录运行。


## 第二轮增量：参考图与 Tripo 软件链路

- 新增私人参考图库：JPEG/PNG 完整解码、校正方向、移除元数据，归一为 PNG；限制大小、像素和账号图库容量。图片内容按哈希检查，已被任务引用的图不可删除。
- 工作室支持上传、选择、预览，图生/文生分开。提交前确认框展示实际发送内容；图片模式不把本地文字说明发送给 Tripo。
- 新任务默认采用官方 v3 文生/图生/文件上传/查询合同；固定保存接口、模型与输入哈希。旧 v2 任务仍查旧接口；无法还原的历史配置明确标为推断。
- 新建 Tripo 任务需要配置本地累计提交次数。名额和任务同一事务创建，并发及重复点击不会重复占用；默认 0。此功能不是积分查询或金额封顶。
- 上传失败、提交未知、查询/下载失败、本地准备失败分别处理；未知提交不会自动重新 POST，下载后的本地失败恢复不重新生成。
- 模型配置变更时旧确认失效；退出/会话过期清空私人草稿；转换器失败留下的部分 STL 不进入制造包。

## 第三轮增量：模型读取、朝向尺寸与版本试装

- 服务端统一解析静态 GLB，浏览器使用同一解析结果，避免前后端对场景变换的解释不一致。新增父子节点变换、镜像绕序、稀疏/量化/交错数据和三角带/扇支持；资源超限、压缩、动画、骨骼、损坏结构等明确报错。
- 制造版本可分别查看原稿比例、毫米装饰草案、最终 STL。原稿预览仅适应视图，不假定制造尺寸；最终文件能放到灯体上进行数字试装。加载失败显示错误，不替换为演示模型。
- 有 GLB 原稿时支持三个轴旋转、目标宽度/深度及两种比例方式；只有最终 STL 时仅开放安装轴旋转。保存参数会创建新草案，并固定源版本、源文件哈希和接口快照。
- 未安装 OpenSCAD 时可以保存装饰草案，不能凭它批准制造。人工导入的最终 STL 不继承不准确的变换记录。原始 GLB 和原稿预览保持私有。
- 旧版本不会被就地改写；新预览文件与调整结果都随新版本保存。已制作实例继续引用原先的固定文件。
